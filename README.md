# 2D Rigid Body Physics: CCD vs Multi-Rate Simulation

## Внешние зависимости

* **Компилятор:** C++17
* **Графическая библиотека:**: (https://www.sfml-dev.org/download/sfml/2.6.2/)
  * `sfml-graphics` (`sfml-graphics-d.lib` / `sfml-graphics-d-2.dll`)
  * `sfml-window` (`sfml-window-d.lib` / `sfml-window-d-2.dll`)
  * `sfml-system` (`sfml-system-d.lib` / `sfml-system-d-2.dll`)

## Кнопки управления

1. Режим DISCRETE_60 - дискретная симуляция всей сцены на 60 Гц 
2. Режим CCD - непрерывное обнаружение столкновений Swept AABB для быстрых снарядов 
3. Режим MULTI_RATE - обычные объекты на 60 Гц, быстрые снаряды на 240 Гц
4. Режим ALL_240 - расчёт всей сцены на 240 Гц
5. SPACE - Выстрелить дополнительным снарядом в тонкую стенку 
6. R - Reset симуляции
7. P - Поставить симуляцию на паузу / снять с паузы
8. N - Выполнить один шаг физики в режиме паузы

## Инструкции по сборке
1. Скачайте SFML библиотеку (по ссылке выше) и подключите их к проекту
2. Закиньте три .dll файла в папку debug
3. PROFIT!111!!!1
